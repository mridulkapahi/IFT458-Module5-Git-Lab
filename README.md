# IFT458-Module5-Git-Lab
Module 5 Activity 1 - Introduction to Git with VSCode
## About This Project

This repository is for my IFT 458 Module 5 Activity 1 assignment.

In this activity, I am learning how to use Git with Visual Studio Code.

The main tasks include:
- Cloning a repository from GitHub
- Editing and saving a file
- Staging changes using Source Control
- Committing changes
- Pushing the changes back to GitHub

This activity helps me understand how Git tracks changes in a project.
